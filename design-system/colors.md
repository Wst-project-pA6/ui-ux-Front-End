# Colors

WST Colors collection — semantic tokens bound to components.

## Base

| Token | Hex | Usage |
| ----- | --- | ----- |
| `background` | `#F8FAFC` | Page background |
| `surface` | `#FFFFFF` | Cards, panels |
| `border` | `#E5E7EB` | Dividers, outlines |

## Text

| Token | Hex | Usage |
| ----- | --- | ----- |
| `text/primary` | `#0F172A` | Headings, body |
| `text/secondary` | `#64748B` | Labels, captions |
| `text/muted` | `#94A3B8` | Placeholder, disabled |
| `text/on-accent` | `#FFFFFF` | On blue / dark surfaces |

## Accent

| Token | Hex | Usage |
| ----- | --- | ----- |
| `accent/default` | `#2563EB` | Primary actions |
| `accent/hover` | `#1D4ED8` | Hover state |
| `accent/soft-bg` | `#DBEAFE` | Ghost backgrounds |

## Sidebar

| Token | Hex | Usage |
| ----- | --- | ----- |
| `sidebar/bg` | `#0F172A` | Nav background |
| `sidebar/text-inactive` | `#94A3B8` | Inactive nav items |
| `sidebar/text-active` | `#FFFFFF` | Active nav items |

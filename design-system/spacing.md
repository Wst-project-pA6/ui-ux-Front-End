# Spacing & Radius

4px base scale.

## Spacing

| Token | Pixels |
| ----- | ------ |
| `--wst-space-4` | 16px |
| `--wst-space-8` | 32px |
| `--wst-space-12` | 48px |
| `--wst-space-16` | 64px |
| `--wst-space-20` | 80px |
| `--wst-space-24` | 96px |

Page rhythm: sections separated by 24px (`space-y-6`), cards padded 20–24px,
table cells padded 12–24px.

## Border radius

| Token | Value | Used for |
| ----- | ----- | -------- |
| `--wst-radius-sm` | 8px | Buttons, inputs, chips |
| `--wst-radius-md` | 12px | Cards, panels, modals |
| `--wst-radius-full` | 9999px | Badges, avatars, pills |

## Effects

- Card shadow: `0 1px 3px rgba(0,0,0,.07)` (`--wst-shadow-card`)
- Focus ring: accent at 25% opacity, 3px spread (`--wst-focus-ring`)

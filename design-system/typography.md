# Typography

Inter throughout — weights 400 / 500 / 600 / 700.

| Style | Size | Weight | Color | Usage |
| ----- | ---- | ------ | ----- | ----- |
| Page Title | 24px | 700 | `#0F172A` | Screen headings |
| Page Subtitle | 13px | 400 | `#64748B` | Screen subheadings |
| KPI Number | 32px | 700 | `#0F172A` | Dashboard metrics |
| KPI Label | 13px | 500 | `#64748B` | Metric captions |
| Table Header | 11px | 600, uppercase, +0.5px tracking | `#94A3B8` | Column headers |
| Table Body | 14px | 400 | `#0F172A` | Cell content |
| Nav Item | 14px | 500 | `#0F172A` | Sidebar links |
| Button Label | 14px | 600 | `#0F172A` | Action labels |

Identifiers (job numbers, VINs, plates, SKUs, amounts) always render in LTR
format, including on Arabic / RTL screens.
